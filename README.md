# Skill Exchange Platform

SkillExchange is a platform where users can request to learn skills they want and offer skills they know. For example, a user could request to learn Java and in exchange offer to teach Python.

Users can:
* Register, log in and manage their profile
* Manage the skills they offer and want to learn
* Search for users to exchange with
* Request and manage exchanges
* Complete exchanges and leave ratings

Admins can:
* View and manage users
* Create, view and manage skills
* View basic statistics


## Tech Stack

* Frontend - React, Vite, Tailwind CSS
* Backend - Node.js, Express.js, Prisma
* Database - PostgreSQL
