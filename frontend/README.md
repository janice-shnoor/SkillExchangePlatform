# Skill Exchange Frontend

The frontend is the user interface for the SkillExchange platform.


## Main Routes

| Route              | Description                       |
| ------------------ | --------------------------------- |
| `/`                | Landing page                      |
| `/login`           | User login                        |
| `/register`        | Account creation                  |
| `/forgot-password` | Password recovery                 |
| `/reset-password`  | Password reset                    |
| `/dashboard`       | User dashboard                    |
| `/discover`        | Search functionality              |
| `/profile`         | User profile and skill management |
| `/exchanges`       | Manage exchanges                  |
| `/messaging`       | Messaging between users           |
| `/admin`           | Administrative controls           |


## Authentication

Protected and guest routes are used to control who has access based on authentication and role.
